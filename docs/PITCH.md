# The sharper entry

**Chat Ships It — the audience has commit access.**

“Twitch chat has always been able to play the game. Now it can change the rules. A viewer pitches a mechanic, chat votes, and Codex writes the patch while the streamer keeps playing. If the checks pass, the new rule lands live. Chat writes the patch notes.”

## What makes the demo land

Open with the consequence. Show a rock breaking into tiny ducks, then reveal the single viewer proposal that caused it. Give the audience one clear choice to make. Keep the live coding visible, but keep the game bigger. Hold one beat on the validation checks, then ship with a decisive color change and credit card. Let the streamer roll back without losing the run.

The differentiator is the visible, attributed journey from audience intent to an agent-written rule in a running game. Do not claim this is the first such product; that would need research. Do not spend the opening minute explaining architecture.

## Submission copy draft

Chat Ships It turns Twitch chat into a live game-design room. Viewers propose a twist to a space survival game and vote on finalists. After the streamer approves, an embedded Codex SDK worker writes a declarative TypeScript mod. A strict syntax parser, bounded schema and deterministic simulation validate the artifact before the game installs it without restarting. Viewers see the agent activity, source file and gate results beside the game, then the proposer receives on-screen credit. Rollback and emergency stop keep the streamer in control.

Codex is part of the runtime: one thread generates each candidate source file, streamed events power the build room, structured output makes artifacts machine-readable, and validator diagnostics drive a single repair attempt. The first measured local generation completed in 14.4 seconds. Live free-form ideas are screened with Gemini before Codex receives a neutral capability spec. The project includes an explicitly labeled credential-free rehearsal and a real-agent mode using reviewed starter specs.

## Scope discipline

Prioritize a flawless real Twitch round, readable OBS capture, fast agent generation and unmistakable mechanic changes. Skip native Predictions, Channel Points, raid relay, arbitrary scripts, multiplayer and complex cloud architecture until that is repeatable. A confidence vote costs nothing and works without Affiliate access.
