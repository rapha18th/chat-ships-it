# Chat Ships It

The streamer creates. The community decides. Codex ships.

A channel owner describes a world. Codex creates a playable game. The owner previews it and publishes it. Twitch chat proposes the next rule. The community votes. Codex writes the patch. The engine validates it and ships the change.

## Evidence

The controlled Twitch round generated Rainbow Honeyglow in 21.354 seconds. All four checks passed. The patch preserved the garden, bee, collector engine, target score, timer, and magnet pickups. Rollback restored the previous rule.

The owner creator also generated Honeyglow Hustle, accepted manual preview input, and published the game. A separate Glow Pollen draft supplied the private-preview image. It was discarded after capture.

Type checking, the production build, and 17 tests pass. The tests cover game creation, previews, persistence, chat evolution, validation, cancellation, and rollback.

## Positioning

Lead with the consequence. A viewer's idea becomes a visible game rule. Show the idea, the choice, the build, and the result. Keep the game readable. Keep the owner in control. Let the product explain its value through a complete working sequence.
